# Security policy

Litecoin Cash DEX Mobile is experimental cryptocurrency software. Use only amounts you are prepared to lose.

## Sensitive information

Never disclose seed phrases, private keys, wallet passwords, PINs, RPC passwords, signing keys, API credentials, or wallet databases. Maintainers will never request a seed phrase or private key.

## Reporting vulnerabilities

Do not publicly disclose an exploitable vulnerability before maintainers can investigate it. Use GitHub private vulnerability reporting when available, or contact maintainers through [litecoincash.com.br](https://litecoincash.com.br). Never include real wallet secrets in a report.

## Wallet safety

- Store the recovery phrase offline and test recovery.
- Verify release checksums, addresses, amounts, and fees.
- Use an uncompromised device protected by an operating-system lock.
- Keep sufficient native coin balance for transaction fees.
- Keep network connectivity available while a swap is active.
- Do not force-stop the application during an active swap unless recovery requires restarting it.

The application depends on third-party blockchains, Electrum servers, KDF peers, market providers, and network services outside the maintainers' control.
